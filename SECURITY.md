# Security Policy

## Supported Versions

Only the latest commit on the `main` branch receives active security updates and patches.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability or potential credential leak mechanism, please report it responsibly:

1. **GitHub Security Advisory (Preferred):** Open a private security advisory through the repository's **Security > Advisories** tab on GitHub.
2. **Email:** If you cannot use GitHub Security Advisories, please report the vulnerability to maintainers at:
   `105177734+yegear1@users.noreply.github.com`

### What to Include in Your Report
- A clear description of the issue and potential security impact.
- Step-by-step instructions or proof-of-concept to reproduce the vulnerability.
- Any suggested mitigations or patches if available.

### Response Time & SLA
- **Initial Acknowledgement:** Within **48 hours**.
- **Assessment & Triage:** Within **5 business days**.
- **Resolution & Release:** A patched release or workaround will be published as promptly as possible, followed by public disclosure after coordination with the reporter.

Please do not open public GitHub issues or discussions for sensitive security vulnerabilities.
